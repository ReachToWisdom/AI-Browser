# AI Browser → AI Kite (Windows)

Windows용 AI Browser는 AI Kite와 일반 Kite를 함께 제공하는 설치본으로 이어집니다.

- [AI Kite / Kite Windows 설치 파일](https://github.com/ReachToWisdom/AI-Browser/releases/download/v2.4.0/AI-Kite-2.4.0-x64-setup.exe)
- [변경 사항과 설치 안내](https://github.com/ReachToWisdom/AI-Browser/releases/tag/v2.4.0)
- SHA-256: `AA0BAA1E2804AA08FE5360E8BBF17D3E90954AD9B2F659BCA5F57A3C7F17A591`

기존 AI Browser의 AI 탭 설정을 사용하며, 새 AI Kite 프로필을 만드는 경우 기존 WebView 프로필을 이전합니다. 설치 시 기존 Kite 설정과 북마크는 유지됩니다. 이 설치본은 Windows 전용이며, macOS용 새 버전은 제공하지 않습니다.
